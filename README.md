# 耳朵靈光不漏聽｜長者聽力保健 網頁型簡報

🔗 線上版：https://mattsue1003.github.io/hearing-health-for-seniors/

「活出青春 3.0：健康存六力」第七堂「聽覺力」的課堂簡報。單一 `index.html`，可上下捲動，也可用上一頁／下一頁或鍵盤方向鍵一頁一頁切換；手機、平板、投影機皆可。

## 內容（41 頁）

開場：封面（含 QR code）、講師介紹、今天聊什麼（含十週課程表）
體適能・腦適能：猜歌暖身（10 首老歌：播放 → 提示歌手 → 公布歌名）、金曲猜歌影片、杯子舞節奏口訣
講堂：為什麼要顧好聽力、聽力測試影片、搓手聽力測試、《大叔日記》影片、8 個警訊（互動勾選）、家人溝通 4 要 3 不
每天護耳：護耳操影片與五撇步、護耳 4 原則、耳垢、乾耳油耳、耳垢軟化劑、耳朵進水、就醫警訊
3 個常見問題：耳鳴、耳石暈眩（含與梅尼爾氏症的差別）、耳中風，各兩頁；聽力與跌倒、前庭訓練
助聽器與資源：買助聽器 4 步驟、互動問答（耳膜／耳模、耳模材質）、戴助聽器小秘訣、助聽器銀行與服務流程、真耳測試、政府補助流程與金額、更多資源
總結：今天的重點、回家作業、我們下週再見、參考資料

## 操作

- `→` `↓` `空白鍵` `PageDown` 下一頁；`←` `↑` `PageUp` 上一頁；`Home` `End` 首尾；`F` 全螢幕；`Esc` 關閉視窗。
- 上方「目錄」可直接跳頁；右側圓點也可跳頁（桌機）。
- **任何文字卡片點一下就會放大成全螢幕視窗**，方便講師講解與長輩閱讀。
- 影片點一下在本頁燈箱播放；若電視台關閉內嵌，按「在 YouTube 開啟」。
- 猜歌頁每首歌有「播放／提示／答案」三個按鈕，播放時燈箱會遮住影片標題避免洩題；警訊頁點選項目會即時計數並給建議；問答頁點選後揭曉答案。
